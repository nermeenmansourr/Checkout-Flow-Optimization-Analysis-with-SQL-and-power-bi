 Checkout Flow & Payment Optimization Analysis
Tools: SQL Server | Power BI | DAX

Timeframe: July 1, 2022 – January 31, 2023

📌 Executive Summary
Analyzed the 365 platform’s checkout funnel using SQL and a 3-page Power BI story dashboard to identify payment bottlenecks, reduce cart abandonment, and increase conversion rates.

🎯 Key Metrics & Definitions
Successful Checkout: Completed subscription payment without issues.

Failed Checkout: Attempted payment but encountered technical/bank errors.

Abandoned Cart: Added item to cart but left before paying.
